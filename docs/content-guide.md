# 使い方ガイド・無料ツールの運用ガイド

公開ページ（`/guide`・`/tools`）の内容を追加・更新する手順と、スクリーンショット・GIF用コンポーネント `<Shot />` の使い方をまとめます。

## 構成

| 場所                                   | 役割                                                                                |
| -------------------------------------- | ----------------------------------------------------------------------------------- |
| `lib/guide-pages.tsx`                  | ガイド9ページの本文データ（1ファイルで管理）                                        |
| `components/GuideParts.tsx`            | `Section` `Step` `Note` `P` `Ul` `Fold` `Toc` `InlineCta` `Shot`                    |
| `components/PublicHeader.tsx`          | `/guide`・`/tools` 共通ヘッダー（ロゴ・使い方・無料ツール・ログイン／アプリを開く） |
| `components/GuideAuth.tsx`             | ログイン状態で表示を切り替える `GuestOnly` `PageCta` `useIsLoggedIn`                |
| `components/GuideFigures.tsx`          | 実画面の部品を使った図（`Fig*`）と手順の流れ図（`Flow`）                            |
| `app/guide/page.tsx`                   | ガイド一覧（ハブ）                                                                  |
| `app/guide/[slug]/page.tsx`            | 各ガイドのページ（目次・途中のデモ誘導・関連ガイドを自動で付ける）                  |
| `lib/tools.ts`                         | 無料ツールの一覧データ                                                              |
| `app/tools/**` / `components/tools/**` | 無料ツールのページと本体（すべてブラウザ内で計算）                                  |
| `app/sitemap.ts`                       | ガイド・ツールの各ページを自動でサイトマップに追加                                  |

ページを足すときは、データを1件追加するだけで、一覧・サイトマップ・前後リンク・目次が更新されます。

## ヘッダーと導線・ログイン状態

- `/guide`・`/tools` は、履歴に頼る「戻る」ボタンではなく `PublicHeader`（ロゴ→トップ、使い方、無料ツール、ログイン／アプリを開く）を使います。ページの階層は、各ページ上部のパンくずと、末尾の「次に読むなら」「前後のガイド」で示します。
- 登録を促す表示（「無料で始める」「デモを試す」、ツール内の登録リンク）は、ログイン中は出しません。未ログインのときだけ表示したい要素は `<GuestOnly>…</GuestOnly>` で包み、ページ末尾の行動ボタンは `<PageCta />` を使います（ログイン中は「タスク一覧を開く」になります）。
- 判定はブラウザのCookie（`sb-…-auth-token`）をマウント後に見ています。サーバー側で判定しないのは、ページを静的に生成して高速に配信するためです。そのため、ログイン中でも、描画の直後は一瞬だけ空欄になります（高さは確保しています）。

## ガイドのページを追加・編集する

1. `lib/guide-pages.tsx` の `GUIDE_PAGES` に1件追加します（`slug` `title` `description` `summary` `related` `body`）。
2. `body` は `<Section title="…">` を並べます。`title` は目次とページ内リンク（`id`）に使われるため、**同じページ内で重複させない**でください。
3. `related` は `{ slug, reason }` の配列です。`reason`（読む理由）が「次に読むなら」に表示されます。
4. 画面名・ボタン名は、実際のUI表記に合わせます。UIの文言を変えたら、ガイドの文言も更新してください。
5. 中身のないページは公開しません。書き終えたものから配列に追加します。

### セクションの組み立て

基本形は「見出し + 図（または短い手順）+ 折りたたみの詳しい説明」です。

```tsx
<Section title="タグで分類する">
  <FigTagPicker />          {/* 図は折りたたみの外に置く */}
  <Fold>
    <P>詳しい説明はここ。折りたたまれるが、本文はHTMLに残る。</P>
    <Step num={1} title="…">…</Step>
  </Fold>
  <Note tone="warn">重要な注意は折りたたみの外に置く。</Note>
</Section>
```

- 折りたたみ内の文章は、検索エンジンが読める本文として残ります。読む量を減らすために文章を消さないでください（コンテンツ量は広告審査にも影響します）。
- 返金・削除など、読み飛ばされると困る注意は `Note` を折りたたみの外に置きます。

### 図（`Fig*`）と `<Shot />` の使い分け

| 使うもの                     | 向いている場面                                                                               |
| ---------------------------- | -------------------------------------------------------------------------------------------- |
| `Fig*`（`GuideFigures.tsx`） | 構造や位置関係の説明（ヘッダーの番号付き解説、ステータスの流れなど）。UI変更に自動で追従する |
| `<Shot />`                   | 本物の画面を見せて安心させたいとき、操作の流れをGIFで見せたいとき                            |

## `<Shot />` の使い方（スクリーンショット・GIF）

### 1. 画像を用意する

- **撮影はデモ画面（`/demo`）がおすすめです。** ダミーのデータだけが入るため、実ユーザーの名前・メールアドレス・依頼内容が写り込みません。本番アカウントの画面を使う場合は、個人情報・依頼先名・金額を必ずぼかすか、ダミーに置き換えてください。
- ブラウザの幅は、PC画面なら1200px前後、スマホ画面ならスマホの実機またはデベロッパーツールのスマホ表示で撮ります。
- 形式は、画面のスクリーンショットならPNG（またはWebP）、操作の動きを見せるならGIFです。
- 容量の目安は、PNG・WebPが1枚300KB以下、GIFが2MB以下です。GIFは長さを5〜10秒、幅を800px程度に抑えます。大きいとページの表示が遅くなり、離脱の原因になります。

### 2. `public/guide/` に置く

ファイル名は、ページと内容がわかる英数字とハイフンにします。

```
public/guide/tasks-and-status-list.png
public/guide/tags-and-calendar-calendar.png
public/guide/images-upload.gif
```

`public/` 以下のファイルは、サイトの `/guide/…` のURLでそのまま配信されます（ミドルウェアは `.png` `.jpg` `.gif` `.webp` などの静的ファイルを通しません）。

### 3. セクションの中に書く

```tsx
import { Shot } from "@/components/GuideParts";

<Section title="一覧カードの読みかた">
  <Shot
    src="/guide/tasks-and-status-list.png"
    alt="納期が近いタスクが赤い枠で強調された一覧画面"
    width={1200}
    height={800}
    caption="納期が7日以内のタスクは、赤い枠で強調されます。"
  />
  <Fold>…</Fold>
</Section>
```

| props              | 必須   | 説明                                                                                                                                     |
| ------------------ | ------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `src`              | はい   | `/guide/` から始まるパス。末尾が `.gif` のときは最適化せず、そのまま配信します                                                           |
| `alt`              | はい   | 画像の内容を表す文章。画像が表示されないときや、読み上げで使われます                                                                     |
| `width` / `height` | はい   | **画像の実寸（ピクセル）**。表示サイズではなく、縦横比とレイアウトのずれ防止に使います                                                   |
| `caption`          | いいえ | 画像の下に出す説明。1文で、「何を見る画像か」を書きます                                                                                  |
| `maxWidth`         | いいえ | 表示の上限幅（px）。中央に寄せます。**スマホの縦長スクショは `maxWidth={320}` 前後にします**（指定しないと本文の幅いっぱいに広がります） |

スマホ画面の例です。

```tsx
<Shot src="/guide/notifications-push.png" alt="ホーム画面に追加した状態のアプリ"
      width={780} height={1688} maxWidth={320} caption="ホーム画面に追加すると、アプリのように起動できます。" />
```

### 4. 書くときの注意

- **`alt` は具体的に書きます。** 「スクリーンショット」ではなく、「何が写っているか」を書きます。
- **画像だけで説明を完結させません。** 図の近くに、見出しと1〜2文の説明を置きます（折りたたみの中の文章で構いません）。
- **GIFは1ページに1〜2枚まで。** 多いと表示が重くなります。
- **UIを変更したら撮り直します。** 古い画像が残ると、ガイドと実画面のずれで逆に混乱を招きます。画像を差し替えるときは、同じファイル名で上書きするか、`src` を新しいファイル名に変えてください（ブラウザのキャッシュで古い画像が残る場合があるため、別名にするのが確実です）。
- `public/guide/` の画像は、使わなくなったら削除します。

## 無料ツールを追加する

1. `lib/tools.ts` の `TOOLS` に `slug` `title` `summary` `description` を追加します。
2. `components/tools/` にツール本体を `"use client"` のコンポーネントとして作ります。入力は**サーバーに送信しない**作りにします（ページの説明文にも「ブラウザ内で処理される」と書いています）。
3. `app/tools/<slug>/page.tsx` を作り、`ToolPageShell` で包みます。`explanation` に、使い方・結果の読みかた・考え方の解説文を入れます（ツールだけの薄いページにしないため）。
4. 日付に依存する初期値は、サーバー描画とのずれを避けるため、`useEffect` の中（マウント後）で入れます。
5. 税金・法律に関わる計算には、注意書き（`Note tone="warn"`）を必ず付けます。

## 広告の対象ページ

広告スクリプトは `components/AdSenseLoader.tsx` で、次のページだけに読み込みます。

- `/`（未ログイン時のみ）、`/guide`、`/guide/*`、`/tools`、`/tools/*`

`/terms` `/privacy` `/tokusho` のような定型文だけのページと、ログイン後の画面・ログイン画面・デモ・エラー画面には出しません。対象を変えるときは、`AD_ALLOWED_PATHS`（完全一致）と `AD_ALLOWED_PREFIXES`（前方一致）を編集し、AdSenseのポリシーとページの内容を確認してください。
